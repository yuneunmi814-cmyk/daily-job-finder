# 🧑‍🌾 일자리 알리미

인력사무소나 시청에 직접 가봐야만 알 수 있던 일자리를, 집에서 휴대폰으로 확인하기 위한 웹앱.

- 제천 인근 12개 시군청(제천·단양·충주·원주·영월·영주·문경·음성·진천·괴산·평창·정선) 공고에서 **채용/공공근로/기간제** 공고를 걸러내고
- 한국노인인력개발원(노인일자리여기)의 **시니어 구인정보**를 합쳐서
- 지역별로 **접수 중인 것만** 큰 글씨로 보여주고, 공고마다 **전화 걸기** 버튼을 붙인다.

## 실행

```bash
node server.js
```

`http://localhost:3465` 로 접속. 설치할 의존성은 없다 (Node 20 이상, 내장 fetch 사용).

인증키는 `.env` 파일에 둔다 (git에 올라가지 않음):

```
SENURI_KEY=공공데이터포털에서_발급받은_인증키
```

## 데이터 출처

| 출처 | 방식 | 갱신 |
|---|---|---|
| 제천시청 고시·공고 | RSS (`rssBbsNtt.do?bbsNo=18`), 최근 50건 ≒ 2주치 | 10분 |
| 단양·충주·원주·영월·영주·문경·음성·진천·괴산·평창·정선 | 새올(eminwon) `OfrAction.do`, **게재 중인 채용공고만** | 10분 |
| 노인일자리여기 | 공공데이터포털 OpenAPI `SenuriService`, 최근 1만 건 | 10분 |

서버가 뜰 때 한 번 받아두고 10분마다 갱신하므로, 사용자는 기다리지 않는다.

### 시군을 더 추가하려면

- 시청 홈페이지에 RSS가 있으면 `CITIES` 배열에 한 줄 추가 (제천 방식)
- 새올(eminwon)을 쓰면 `EMINWON_CITIES` 에 `host`만 추가. `eminwon.<시군>.go.kr` 주소가 열리는지만 확인하면 된다 (도메인이 다른 곳도 있음: 문경=gbmg, 영월=yw, 평창=pc, 횡성은 새올 미사용).
- 채용공고 분류(`not_ancmt_se_code=05`)가 비어 있는 시군(괴산 등)은 자동으로 전체 분류에서 제목 키워드로 골라낸다.

### 노인일자리 지역 검색에 대해

목록 API는 지역명을 주지 않고 지역코드만 준다(2026-08-09 확인). 그래서 접수 중인 공고에 한해 상세 API를 한 번씩 호출해 주소를 받아 캐시하고, 그 주소로 지역을 판별한다. 상세 API는 한꺼번에 많이 부르면 실패하므로 **동시 3건 + 120ms 간격**으로 나눠 호출한다(그 이상은 실패율이 급증). 공고 내용은 바뀌지 않으므로 한 번 받은 상세는 계속 재사용한다.

## 공고를 거르는 기준 (server.js)

- `JOB_WORDS` — 채용·기간제·공공근로·근로자, 또는 "○○ 모집"(강사/관리원/도우미 등 사람을 뽑는 말)
- `NOISE_WORDS` — 합격자 발표, 입주자 당첨, 비자사업, 위탁기관 모집처럼 일자리가 아닌 공고
- 마감일은 본문의 "접수기간 : … ~ 8. 14." 에서 뽑는다. 첨부파일에만 있어 못 뽑는 경우 게시 후 3주간 노출하고 화면에 "마감일은 공고문 확인"이라고 표시한다.

> 걸러진 결과가 이상하면 이 두 정규식만 손보면 된다.

## 배포 (Render 무료 플랜 기준)

1. 이 폴더를 GitHub 저장소로 올린다. **`.env`는 올라가지 않는다** (`.gitignore`에 있음).
2. [render.com](https://render.com) 가입 → New → Web Service → 그 저장소 선택.
3. `render.yaml`이 있어서 빌드·시작 명령은 자동으로 잡힌다.
4. **Environment → Add Environment Variable** 에서 `SENURI_KEY` 에 인증키를 직접 입력한다.
5. 배포되면 `https://…onrender.com` 주소가 나온다. 휴대폰으로 열고 **"홈 화면에 추가"** 하면 앱 아이콘처럼 쓸 수 있다.

무료 플랜은 15분간 접속이 없으면 잠들었다가 다음 접속 때 30초쯤 걸려 깨어난다.

## 아직 안 된 것

- **일용직(워크넷/고용24) 데이터** — 고용24 API 키 발급 후 연동 예정. 단, 공공데이터포털 기준 이용허락범위가 **제4유형(상업적 이용금지)** 이므로 사업화할 경우 별도 확인 필요.
- **화면을 꺼도 오는 푸시 알림** — 지금은 앱을 열어둔 동안만 10분마다 확인해서 알린다. 진짜 푸시는 배포(HTTPS) 후 Web Push를 붙여야 한다.
- **인력사무소 일감** — 디지털화된 데이터가 없어서, 동네 사무소와 직접 협의해 수기로 올리는 방식부터 검증해야 한다.
- 충주 일부 공고는 본문이 비어 있고 첨부 HWPX에만 내용이 있다. 이 경우 "공고 원문 보기"로 넘긴다.
- 라이선스: 제천/단양/충주 공고는 공공누리 제2·4유형(출처표시, 상업적 이용금지)이다. 비상업 용도면 문제없으나 수익화 시 확인 필요.
